# AuralWarden 1.4.1 — Presentación del texto

## Correcciones

- Justificación de los párrafos en todas las secciones con texto explicativo, transcripción en vivo, subtítulos, biblioteca e historial.
- Criterio compartido para preferencias, preparación de modelos, separación de audio, perfiles de voz, presets, momentos, temporizador, almacenamiento y mensajes de confirmación.
- «Acerca de» redimensionable, con texto seleccionable, ajuste de rutas largas y acceso directo a los avisos de terceros incluidos en la aplicación.
- Conservación de los títulos, botones, etiquetas breves, marcas de tiempo y resaltado de hotwords.
- Preferencias con desplazamiento cuando la altura disponible no basta para mostrar todos sus campos sin superponerlos.

La última línea de cada párrafo mantiene el espaciado natural; no se estiran las palabras para rellenar artificialmente toda la fila. El ajuste es visual y no cambia los archivos originales, los textos exportados ni el motor de reconocimiento.

## Distribución

Parche local sobre 1.4.0, sin publicación automática ni cambios en los datos de las sesiones abiertas. Conserva el temporizador, el gestor de almacenamiento y la receta reutilizable del instalador. La navegación sincronizada entre transcripción y vídeo sigue reservada para una versión posterior.
